# Suggested commands
- Install: `npm install`
- Register slash commands: `npm run register`
- Start: `npm start`
- Development watcher: `npm run dev`
- Syntax-check changed JS: `node --check src/bot.js` (repeat for other changed JS files)
- Working tree: `git status --short`
- Review changes: `git diff -- <paths>`
- Patch whitespace validation: `git diff --check`
- Windows search convention: use `rg` / `rg --files`; PowerShell is the shell.
